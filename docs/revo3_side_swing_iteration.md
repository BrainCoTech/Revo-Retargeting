# 四指侧摆测试与迭代

本轮“侧摆”指食指、中指、无名指、小指的 MPR 外展／内收。官方模型四轴范围均为约 ±15°。复用登记 DSW 的 CPU 环境和原始碰撞网格；不开展硬件能力测试。算法为实验性 opt-in 模块，没有替换既有对指求解器。

## 测试层次

1. 数值层：15 个已知角度组合，侧摆 −12°／0°／+12°，屈曲 0°／45°／70°／110°／120°；独立校验解出的侧摆符号与幅值。另外检查不可观测／缺失输入超时回中立。
2. 合成时序层：固定骨段长度，四指同步 ±12° 往复；依次经历伸直、60°、120°、90° 屈曲，90° 段加入固定随机种子的方向噪声，最后回中立。120° 是角度分支压力测试，超出机器人 MCP 85° 范围；机器人按既有限位处理。该数学骨架未验证人体解剖可行性。
3. 真人诊断层：MANUS finger_agility 24–27 秒、hand_mobility 18–21 秒。根据侧摆投影变化较大选为压力窗口，并非独立测试，也没有真实侧摆关节角标签。真人数据只能报告跟踪、饱和、可观测性和碰撞，不能把这些量写成源角度准确率。
4. 动力学层：每种候选均用相同源输入、30 Hz 限速指令与 500 Hz 物理步执行；保存目标、限速后指令、实际状态及每步最深碰撞的部件名。拇指指令为中立，仍参与碰撞。

## 候选与问题归因

| 候选 | 处理 | 用途 |
|---|---|---|
| legacy | 原始 MCP→PIP 与 CMC→MCP 在掌 yz 平面中的角度差，裁到限位 | 保留当前角度基线 |
| wrapped | 将投影直线角度差按 π 周期统一分支 | 检验屈曲越过 90° 引起的方向翻转 |
| observable | 在 wrapped 基础上加可观测性滞回、短暂保持、超时回中立 | 避免近 90° 时微小噪声使角度跳变 |
| collision | 保留 observable 的四个侧摆目标，调整其余四指屈曲量降低原始 mesh 穿透 | 分离侧摆估计问题与全手碰撞问题 |
| retreat | 在固定网格上先减少屈曲，必要时再减少侧摆，取首个静态穿透 ≤0.05 mm 的姿态 | 保守避碰兜底，必须报告动作幅度损失 |

投影可观测性定义为掌 yz 平面中的向量长度与完整向量长度之比，取掌骨和近节两者中的较小值。恢复阈值 0.30、失效阈值 0.20；失效最多保持 0.25 秒，之后目标回中立，实际命令始终经过速度／加速度限制。该策略不能凭骨架位置恢复完全不可观测的侧摆角，也没有建立设备特定的中立位校准。

π 周期分支处理假定人手侧摆在 ±90° 内；不是普适三维关节角解算。若设备给出可靠的局部关节旋转／骨段姿态，后续应优先使用该信息并验证轴定义。21 点相机骨架仍需要单独的拓扑和不可观测点适配。

碰撞修正不改变网格、碰撞排除、关节限位或验收阈值。只优化 12 个屈曲自由度，侧摆和拇指固定；代价函数包含偏离原屈曲目标与全部实际碰撞的惩罚。必须报告屈曲修正量和收敛比例，不能据此声称完整人手姿态保真。

上述局部优化候选最终未通过真人压力片段。第三轮 retreat 采用步长 0.05 的比例网格，先检查 21 个屈曲比例，再在完全张开屈曲后检查侧摆比例，最多 41 次几何检查。三组动力学门槛都通过，合成可观测侧摆角度保持不变；但真人片段有很大动作退让，因此只作兜底基线，未晋升为真人任务合格映射。不能通过退回中立得到“低碰撞”后省略保真度验收。

## 评价原则

合成输入的可观测角度误差门槛为 0.1°，近奇异段目标每帧跳变门槛为 1°。四指角度真值仅用于合成数据；不可观测段不计算伪准确率，而检查稳定性、超时行为及恢复。

全程沿用最大穿透 ≤1 mm、实际越界 ≤0.02 rad、指令速度 ≤4 rad/s、加速度 ≤20 rad/s²、无仿真告警。命令目标大幅跳变与限速后命令满足运动门槛是不同指标，分别报告。算法门槛通过与整手动力学门槛通过也分开报告。

所有候选含失败结果均保存于 `runs/*_side_swing_*`，每个 run 有输入 NPZ、三层机器人轨迹、指标、逐步碰撞记录、代码快照与 manifest。测试结果与选定状态见 `artifacts/revo3_lab/reports/side_swing_iteration_20260913.md`。

## 复现与下一步

在登记 DSW：

```sh
LAB_ROOT=/mnt/workspace/wensheng/revo3-retargeting-lab
LAB_PY=$LAB_ROOT/envs/core-py312/bin/python
LAB_SCRIPTS=$LAB_ROOT/repos/Revo-Retargeting/experiments/revo3_lab/scripts
"$LAB_PY" "$LAB_SCRIPTS/run_side_swing.py"
"$LAB_PY" "$LAB_SCRIPTS/run_side_swing.py" --candidate collision --no-render
"$LAB_PY" "$LAB_SCRIPTS/run_side_swing.py" --candidate retreat --no-render
```

默认比较原始／分支修正／可观测性三个候选并渲染。`--candidate` 可重复指定；`--no-render` 用于数值迭代。精确历史复现应运行原 run 的 `code/scripts/run_side_swing.py` 并使用其 manifest 中的参数，保留历史阈值与源数据版本。

渲染默认同时展示保存的 25 个输入骨骼点／连线与机器人输出。三种机器人结果时使用四宫格：输入、legacy、observable、retreat。每帧核对输入与输出时间索引，输入区按拇指和四指分色，并标明真人／合成来源。输入已是映射器使用的掌坐标，不重复镜像；显示时只按掌宽归一化并变换到同一观察坐标。机器人画面仍使用保存的实际状态，不重新求解或重跑动力学。

接入新的真人数据时，先采集已标注中立位、张指／并指、单指侧摆及不同屈曲角下侧摆；保留骨段姿态和可信度。分别校准中立偏移、轴方向和可观测性，再考虑幅度缩放。完整真人任务还需独立受试者／session、拇指联动和对指／侧摆切换回归；当前实验不能替代这些验证。
