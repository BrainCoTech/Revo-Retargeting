# 用真实输入验证重定向

当前证据需分开陈述：已有真实 MANUS 短片，但多次查看／调参后它们属于开发验证集；冻结姿态只能测局部稳定；骨长保真的合成运动只能测控制响应与软件回归。它们都不足以验证自然连续揉搓、在线对指切换和真实 ring/little 泛化。

优先建立一个无需新硬件的摄像头采集集。MediaPipe 会新增视觉误差，因此需要把「检测质量」与「映射质量」分开报告。它适合暴露鲁棒性问题，不能取代光学动捕／MANUS 的几何参考，更不能给接触力真值。

## 第一轮可执行采集（每次约 8–10 分钟）

每项连续录 30–45 秒，保留开始、失败、结束全过程，同时录 raw.avi 和原始关键点。先录一轮固定配置基线，再决定修改。动作顺序可以随机，顺序记录在 session 标签或独立人工备注中。

| 输入组 | 动作与变化 | 要暴露的问题 |
|---|---|---|
| 静止与普通运动 | 张手／半握／握拳各保持，慢快交替连续开合 | 静止抖动、骨长漂移、滤波滞后 |
| 五指独立活动 | 单指屈伸、并指／张指、非对称摆动 | 手指串扰、侧摆幅度丢失 |
| 连续对指 | index→ring→middle→little 随机顺序，接近但不接触负例 | 错指、指尖漂移、转换不连续 |
| 自然揉搓 | 改变力度和速度、夹纸／软物体、自然停顿 | 遮挡、拇指深度歧义；只人工标意图 |
| 转腕与视角 | 掌心／手背、斜视、侧视，整体平移前后移动 | 掌基退化、坐标符号与尺度漂移 |
| 失跟与恢复 | 整手出画 0.1/0.3/1 秒、手指遮挡、画面边缘 | 丢失持续时间、恢复跳变、回中立时间 |
| 困难条件 | 弱光、逆光、快运动、双手同框、相似背景 | 模糊、错手、身份跳变、最长失败段 |

第一轮同一人隔天换 session；条件允许再加入不同手型的人和不同摄像头。按 **人 × session × 设备** 分开发／验证／锁定测试集，同一段相邻帧不可随机拆分。已有反复调参的 MANUS 样例只作开发回归。最后测试集在参数冻结后评估；看过结果并据此调参，就需更新它的集合归属。

## 指标与判读

当前程序自动提供逐帧原始数据、失败状态、跟踪比例和处理耗时分位数。后续离线评分应补充这些指标，不能假定已实现：

1. 输入质量：静止段关键点标准差、每条骨长变异、掌宽漂移、丢失段数量与最长持续时间、源 dt 分布。MediaPipe 的 handedness_score 是手侧分类分数，不能当 21 个点的置信度。
2. 映射输出：关节跳变／速度／加速度、限位停留比例、非活动手指串扰、相对指尖距离误差、重获跟踪恢复时间。目标拟合误差仅相对于模型估计输入，不是绝对人手误差。
3. 系统响应：推理／求解 P50/P95/P99，完整采集到显示的实测时延、处理超预算比例。当前 processing_ms 不包含摄像头排队、显示和 JSON 写入，不可称端到端时延。
4. 人工阶段标签：接近／保持／释放／揉搓／失跟。先盲看原视频标意图，再和映射输出对齐，避免根据机器人输出反推真值。没有深度或力传感器时不报告真实接触成功率。要评估动力学接触与穿透，需把保存命令交给原 DSW 评估环境另跑并标明数据域。

按每种条件单独报中位数、尾部与最差片段；同时保留成功和失败分母，不用一条平滑平均曲线掩盖退化。为每类失败记下 run_id、帧号、时间范围、输入视频和配置 hash。先归因于观察／坐标尺度／映射／控制，再改对应层。

## 数据增强的合适位置

在 **同一真实录制** 上加 0/1/2/5 mm 关键点噪声和 0/5/10/20% 掉点，固定种子，原始版与扰动版成对回放。工具已支持 `--noise-mm` 与 `--dropout`。这种独立高斯扰动只是可重复压力测试，不能模拟真实视觉错误的全部相关结构，也不替代真人数据。

下一步增加整段 100–500 ms 丢失、手指链相关误差、时间抖动、深度压缩，参数分布从真实失败数据估计，避免又编出过于整洁的噪声。独立噪声实验和实际困难条件分别报告，合成回归阈值保持原义。

## 本次交付边界

本地工具见 `tools/mediapipe_revo3/README.md`。保留 MediaPipe 原生 21 点，不把不存在的 CMC 点标成观测。它输出官方 Revo3 21 轴运动学命令，用于采集与在线基线观察；不是已验证的接触控制器。真实摄像头完整交互、自然对指／揉搓泛化需用以上采集获得证据。本次程序级检查和公开静态图推理不能抵扣这些项目。
