### 常用入口

以下命令在登记 DSW 执行，不创建新的 Python 环境：

```sh
LAB_ROOT=/mnt/workspace/wensheng/revo3-retargeting-lab
LAB_PY=$LAB_ROOT/envs/core-py312/bin/python
LAB_SCRIPTS=$LAB_ROOT/repos/Revo-Retargeting/experiments/revo3_lab/scripts
"$LAB_PY" "$LAB_SCRIPTS/trajectory_catalog.py" list
"$LAB_PY" "$LAB_SCRIPTS/trajectory_catalog.py" command --case middle_clip_1
"$LAB_PY" "$LAB_SCRIPTS/trajectory_catalog.py" command --case middle_clip_1 --current-code
"$LAB_PY" "$LAB_SCRIPTS/trajectory_catalog.py" build
"$LAB_PY" "$LAB_SCRIPTS/run_opposition_sequence.py"
```

`command` 只打印命令；复制该命令即可执行。默认使用原 run 的代码快照与冻结配置，`--current-code` 用当前代码跑同一输入／配置来检测退化。每次执行均生成新 run。稳定别名为 `index_hold`、`index_agility`、`index_mobility`、`middle_hold`、`middle_clip_1`、`middle_clip_2`、`ring_clip_1`、`little_clip_1`；也支持具体 run ID。`build` 新建不可变目录快照，并刷新可重建的 registry 索引。

## 2. 前几轮迭代留下的有效方法

采用“输入检查 → 静态几何 → 动态跟踪 → 连续任务 → 独立数据”的顺序，每层保留可单独重放的输入和诊断。这样真人数据替换后，可以定位变化发生在哪一层。

| 发现的问题 | 已采用的措施 | 后续继续沿用的原则 |
|---|---|---|
| 仅指尖／相对向量接近，指腹仍未正确相对 | 从原始末节碰撞 STL 取表面位置与法向，优化双侧指腹目标 | 接触区域、法向与碰撞是显式约束；保留原几何 |
| 固定目标能接触，短时真人动作却错过接触窗 | 因果闭合预测与离散制动限速器 | 分开统计源意图、求解目标、指令、实际接触；预测按秒定义 |
| 速度前馈增加穿透或降低覆盖率 | 选定配置保留零速度前馈 | 增加控制项必须通过相同输入、相同门槛的对照 |
| 中指闭合更慢 | 在两个片段上共用 4 帧预测、目标前制动与选定预压 | 不能为每一小段单独设参数来掩盖泛化不足 |
| 无名指／小指出现非目标接触 | 加碰撞约束；小指在固定指腹范围内选横向 +4 mm 表面目标 | 优先检查可达性与目标位置，再调权重；不能扩大指腹或排除碰撞 |
| 小指合成输入没有跨过释放阈值 | 人手 IK 生成约 30 mm 开口，再验证完整闭合与释放 | 先检查源动作是否要求释放，再判断机器人问题 |
| 四个孤立成功不保证切换成功 | 本次增加单次动力学运行、生成中立过渡、全程状态与限速器连续 | 连续任务必须重新运行物理并保存过渡记录 |

当前连续演示重用已求解的 `mapped_goals`，不是重新在线求解源数据。食指→中指→无名指→小指，各段先 1.5 秒接近、1 秒稳定，按原时间运行短片段，再 1.5 秒回中立、1 秒稳定。源片段不拉长；过渡明确标为生成机器人指令。后续要改变动作顺序、取消中立过渡或做五指同时运动，应另建协议与运行，不能直接沿用本次通过结论。

## 3. 真人数据接入契约

保持求解器和动力学模块，新增采集格式适配器与数据质量门。原始文件写入新的版本目录，转换结果写入 `data/normalized/<dataset_version>`；禁止覆盖官方或合成回归输入。

| 字段／约定 | 接入要求 |
|---|---|
| 时间 | `timestamps[T]` 为秒，严格递增，保留原时间及掉帧记录；重采样另存版本与映射 |
| 骨架 | 当前求解器是 `ingest_manus.NAMES` 的 25 点拓扑；`names[25]`、`parent[25]` 与坐标一一对应 |
| 坐标 | `world_positions_m[T,25,3]` 为米；`palm_positions_m`、`palm_basis` 沿用规范化定义；记录设备坐标轴、左右手与校准来源 |
| 有效性 | `observable_mask[T,25]` 与质量记录；新增适配器必须处理不可观测点。当前 solver 不消费 mask，不能直接将缺失点填零后运行 |
| 来源 | 设备、采样率、匿名受试者 ID、session ID、单位、左右手、原始文件 hash、转换版本与校准文件 hash |
| 标注 | 分开存 `partner`、接近／接触／保持／释放阶段、标注置信度、标注方式；力真值不存在时显式为未知 |
| 划分 | 按受试者／采集 session 分 train-tune、validation、final_test，禁止相邻帧跨集合造成泄漏 |

掌坐标定义：原点 Hand；z 指向 Middle_MCP；y 为 Pinky_MCP→Index_MCP 并对 z 正交化；x=cross(y,z)。`source_palm_x_sign=-1` 是当前样本配置，接入新设备必须校准后确定，不能当作所有设备的通用转换。

21 点相机骨架不能直接伪装成当前 25 点：需定义拓扑映射和不可观测 CMC 的估计方法，标注估计点并验证误差；必要时让求解器只消费可观测约束。新的适配器、mask 处理和自动基线生成是下一阶段待实现项，本次没有声明完成。

现有 `run_pinch_clip.py` 可通过配置 `normalized_source` 指向新的规范化 NPZ，但还依赖旧 vector 输出：新序列必须提供同一输入生成的 `legacy_baseline_npz`，不能误用官方 finger_agility 基线。当前时间采样使用最近帧，且求解时默认点有效；真实掉帧／非 30 Hz 输入接入时，应先实现统一重采样、最大允许时间差及无效帧跳过／安全释放策略，再进入评估。

## 4. 后续快速迭代闭环

1. **先接一小批有代表性的真人数据。** 四指各有闭合、两秒保持、释放，另有连续切换、张手负例、近距离不接触、不同速度与掉点片段。保留同步视频用于人工核对。单指与连续任务都需要独立 session。
2. **冻结数据与质量报告。** 查单位、镜像、掌基退化、骨长突变、时间异常、缺失比例；按 session 冻结划分。质量不合格的段隔离并记录原因，不用调 solver 补偿输入错误。
3. **用当前选定配置跑零调参基线。** 输出新真人数据的覆盖率／中断／释放／误触发和耗时；同时跑 catalog 的八个已有选定用例。先看到域差异，再决定改哪里。
4. **按失败类型做小范围对照。** 几何失败查尺度、拓扑、指腹目标；跟踪延迟查预测时长与限速器；错误触发查意图状态机；非目标碰撞查全手目标与切换路径；缺失输入查观测策略。每批固定数据与门槛，改变一个参数族，保存全部候选。
5. **加入真正的连续选择器。** 建议状态为 open→approach(partner)→contact→release→open；用时间滞回与切换仲裁避免抖动。先评估中立过渡，再评估直接切换。保证命令限制器状态连续，并对四组接触都做逐物理步检测以统计误触发。当前演示手指顺序是预先指定的。
6. **验证集选配置，独立集只验收。** 两批无改善即回到失败归因，不反复观看最终集选参数。新配置必须同时通过旧回归、新真人单指、释放负例与连续任务，之后才更新 selected 索引。
7. **最后做在线端到端评估。** 测采集→转换→状态机→IK→命令的 P50/P95/P99、掉帧与 deadline miss。已有 IK 最大耗时约 36–53 ms，超过部分 30 Hz 帧预算；不能把离线 1× 视频当作在线实时性证明。

原仿真门槛继续固定：有效接触覆盖率 ≥95%、最长中断 ≤100 ms、最大总穿透与非目标穿透 ≤1 mm、指令速度 ≤4 rad/s、加速度 ≤20 rad/s²、实际越界 ≤0.02 rad、无仿真告警。保持任务另外要求完整两秒。新数据新增负例误触发率、释放延迟、意图识别与掉点恢复门槛，数值应在看最终集前根据任务需求确定。

源距离 ≤15 mm 是几何近距离标签，20 mm 是当前释放滞回阈值；两者都不是人体接触真值。若要训练教师数据，必须另行验收源标注可靠性、任务成功、轨迹质量与独立真人泛化。当前不导出合格教师标签，也不重复开展用户已确认的硬件能力测试。

## 5. 每次迭代交付物

新数据 manifest／split、质量报告、冻结 config、原始与规范化输入 hash、代码与环境 hash、映射目标／限速指令／实际状态、逐步接触、失败时间索引、对照指标和视频，以及一条完整复现命令。候选全留存，选定索引可更新，原 run 不变。当前新增的 catalog 已提供这一工作流的检索入口；新数据适配与在线状态机按上述顺序实现。
